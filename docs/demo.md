# Демонстрация

Запустите сервис по [README](../README.md). Во втором терминале задайте те же значения `Operators__ivan` и `Reviewers__olga` и выполните `./scripts/demo.ps1`. Для ручного просмотра используйте ID, которые напечатает скрипт, и передайте любой из двух ключей в заголовке `X-Api-Key`.

1. В `demo/invalid.csv` первая запись нарушает форматы пяти полей, во второй не хватает колонок. Отчёт возвращает обе исходные строки с номерами 2 и 3. Сверка с этим пакетом возвращает `422`.
2. Исправленный набор — `demo/internal.csv` и `demo/external.csv`. Повтор загрузки `internal.csv` возвращает тот же ID и `reused: true`.
3. Оба запуска возвращают одинаковые позиции и категории при разных ID запусков.

| Категория | Число | Что смотреть |
| --- | ---: | --- |
| `matched` | 2 | ID `same` и пара для заказа с запятой и кавычками, ровно на границе пяти минут. |
| `amount-mismatch` | 1 | Для `difference` суммы 20.00 и 21.00. |
| `missing-internal` | 1 | ID `only-external`. |
| `missing-external` | 1 | ID `only-internal`. |
| `duplicate` | 3 | Две внутренние и одна внешняя записи с ID `duplicate`. |
| `ambiguous` | 3 | Один внутренний кандидат для двух внешних строк заказа `=order-6`. |

Скрипт закрывает внутреннее расхождение по `=order-6` с комментарием. Без ключа запрос получает `401`. Повтор решения с ключом получает `409`. В `.local/demo-report.csv` категория остаётся `ambiguous`, рядом записаны `olga`, UTC-время и комментарий. Строки заказа и комментария с начальным `=` экспортированы с апострофом для защиты от формул.
