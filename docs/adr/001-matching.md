# Порядок сопоставления

В каждом запуске сначала группируем непустые внешние ID. Если в любом источнике ID повторён, все записи с этим ID, включая одиночную запись с другой стороны, получают `duplicate`. Среди оставшихся совпавшие ID образуют пару. Различие суммы или валюты даёт `amount-mismatch`. Заказ и время не переопределяют точное совпадение ID.

Для оставшихся записей кандидат должен иметь ту же сумму, валюту и заказ и попадать в окно ±5 минут включительно. Если обе записи имеют непустые несовпавшие ID, пары быть не может. Пара подтверждается, когда у обеих сторон ровно по одному кандидату. Счётчики считаются на исходном графе кандидатов до подтверждения пар. Ноль кандидатов означает отсутствующую запись с другой стороны, остальные неподтверждённые записи получают `ambiguous`.

По составному ключу хранятся массивы, отсортированные по времени. Две двоичные границы дают число кандидатов без построения полного графа. Порядок результатов фиксирован ID и исходными номерами строк. Уникальные ограничения PostgreSQL закрепляют участие записи не более чем в одном результате запуска.
