# История запусков и решений

Каждый запрос сверки создаёт новый запуск с двумя ID пакетов и версией алгоритма. Результаты публикуются целиком. Пары и одиночные расхождения хранятся в одной таблице с общей позицией для пагинации и экспорта.

Решение — отдельная запись по ключу запуска и позиции. Автор берётся из учётных данных, время назначает PostgreSQL, комментарий фиксирует причину. Решение не переносится между запусками. Два проверяющих могут открыть одно расхождение одновременно, но сохранить решение удастся одному. Второй получает `409`, первая запись остаётся в аудите.
